# VNC2Go
## A private, in the browser, VNC client.

As the name suggests, this:

- Dosen't keep logs
- Dosen't require an account
- Dosen't fingerprint your browser
- Is littered with ReactJS and ShadCN/ui

It does however:

- Run hCaptcha (may be a concern for privacy geeks)
- Use cloud providers (thats a given)
- Use cookies (CSRF, Anonymous JWT visitor ID)
